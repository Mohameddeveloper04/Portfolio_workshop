# Mohamed M — Personal Portfolio Website

A modern, professional, fully responsive personal portfolio website built with HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Features

- **Dark premium theme** with cyan accent color
- **Responsive design** — works on desktop, tablet, and mobile
- **Smooth animations** — scroll reveal, hover effects, fade-in transitions
- **Project filtering** — filter by category with smooth animations
- **Contact form validation** — client-side validation with error/success messages
- **Sticky navbar** — changes on scroll with active link tracking
- **Mobile hamburger menu** — slide-in panel with smooth toggle
- **Back-to-top button** — appears on scroll
- **Dynamic year** — footer copyright year auto-updates
- **Timeline section** — visual journey/experience display

## ✏️ How to Customize

Search for `<!-- REPLACE:` comments in `index.html` to find all placeholder values that need to be updated:
- **Name & Title** — in the hero section
- **About Me** — bio, education, college, year, location
- **Skills** — add/remove skill tags
- **Projects** — update project names, descriptions, images, and links
- **Journey** — update timeline milestones
- **Contact** — update email, phone, location, and social links
- **Social URLs** — update GitHub, LinkedIn, Instagram links

## 🛠️ Technologies Used

- HTML5 (semantic)
- CSS3 (custom properties, flexbox, grid, animations)
- Vanilla JavaScript (IntersectionObserver, DOM manipulation)
- Google Fonts (Inter)
- Font Awesome (icons via CDN)

## 📦 How to Run

Simply open `index.html` in any modern web browser. No build tools or server required.
